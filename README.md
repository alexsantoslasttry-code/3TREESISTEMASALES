# Sistema V

Sistema interno de vendas e atendimento da 3TreeUniverse (Triuniverse Travel e Business/Benefícios).

- `index.html` — versão de teste (prévia), uma página só. Os dados ficam no banco da prévia no Claude ou, fora dele, no navegador.
- Banco online (Supabase) e WhatsApp: código pronto. Para ativar, siga **ATIVAR-WHATSAPP.md**. Sem as variáveis no Netlify, o sistema continua funcionando como prévia.
- WhatsApp: cada conversa nova vira protocolo 3TU com resposta automática; a equipe responde pelo menu **WhatsApp**, e a mensagem sai pelo mesmo número.

Uso interno. Não colocar dados sensíveis de clientes (CPF completo, cartão, documentos) na versão de teste.
